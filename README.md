# Space Exploration Website 🚀

A modern and interactive Space Exploration Website built using HTML, CSS, and JavaScript. This project is designed to provide users with an immersive journey through the universe while demonstrating frontend web development skills.

## Overview

The Space Exploration Website allows users to:

- Explore the Solar System and learn about all 8 planets.
- Discover famous space missions.
- View a gallery of stunning space imagery.
- Read interesting space facts.
- Experience a futuristic NASA-inspired user interface.
- Interact with animations, timers, and other dynamic features.

## Features

### Home Section
- Full-screen animated space background
- "Explore the Universe" landing page
- Smooth scrolling navigation
- Loading screen

### Solar System
- Interactive planet cards
- Planet information:
  - Name
  - Distance from the Sun
  - Interesting facts
- Hover animations

### Space Missions
- Apollo 11
- Voyager 1
- Curiosity Rover
- James Webb Space Telescope
- Timeline-based layout

### Gallery
- Space image gallery
- Lightbox image viewer
- Responsive design

### Additional Features
- Dark mode interface
- Animated starfield background
- Back-to-top button
- Live digital clock
- Space Fact of the Day
- Rotating Earth animation
- Countdown timer for the next Mars mission
- Background music toggle
- Button click sound effects

### Contact Section
- Contact form
- Social media links
